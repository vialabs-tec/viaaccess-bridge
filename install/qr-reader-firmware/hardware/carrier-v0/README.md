# Carrier v0 — KiCad project

Pilot interconnect PCB for the ESP32-S3 QR Reader appliance. Replaces Dupont
spaghetti: field screw terminals + module headers + 5 V star.

Spec: [`docs/carrier-v0.md`](../../docs/carrier-v0.md)

| File | Role |
|---|---|
| `carrier-v0.kicad_pro` | KiCad 8+ project |
| `carrier-v0.kicad_pcb` | Board (footprints, routed nets, GND pour on `B.Cu`) |
| `carrier-v0.kicad_sch` | Net / connector index (minimal graphics) |
| `gen_pcb.py` | Regenerates the PCB (pad-accurate Manhattan routes) |
| `fab/` | JLCPCB Gerber/BOM/CPL notes |

Board size: **90 × 60 mm**, 2-layer, 1.6 mm.

Regenerate after layout edits in the script:

```bash
python3 gen_pcb.py
```

**Quit KiCad fully** (not only the PCB editor), then reopen `carrier-v0.kicad_pro`.
**Fill all zones**, then **DRC**.

### Routing status (v0)

Autorouted (corridor A\* on F/B + vias) with `B.Cu` GND pour. After regenerate:
quit KiCad fully → reopen → **Fill all zones** → **DRC**.
Pads-only fallback: `UNROUTED = True` in `gen_pcb.py`.

## Design choices

- **J1 DCIN** is a **XH 2P wafer** (pitch 2.5 mm, market “XH2.54”) for the
  female XH housing on the pigtail of a **panel-mount 5.5×2.1 mm** DC jack (P4).
  Pin 1 = `+5V`, pin 2 = `GND`. No field screw terminal for power.
- **J8A / J8B** are two **1×22** female headers (2.54 mm pitch) whose centers are
  **22.86 mm (0.9″)** apart — JLCPCB has no single dual-row 0.9″ part. Plug the
  DevKit **component-side up, USB to the left** (silk tick on J8A). Factory
  GPIOs/power on J8A (DevKit J1); J8B (DevKit J3) pads are NC keepouts.
  Pinout matches Espressif DevKitC-1 v1.1.
- **No BSS138 module.** Relay and buzzer use discrete **2N2222** open-collector
  drivers on the carrier (`Q2`/`R2`/`R3` and `Q1`/`R1`).
- **Relay (`J9`):** `IN` is pulled up to 5 V by `R3` (10k) and sunk by `Q2`
  when GPIO10 is high. In `/setup`, leave **relay active-high unchecked**
  (idle = GPIO high holds `IN` low / relay off; pulse drives GPIO low → `IN` high).
- **Buzzer (`J12`):** 2-wire active / SFM-20B. `+` → 5 V, `−` → `Q1` collector.
  In `/setup`, **buzzer active-high checked**.

### J8A / J8B DevKitC-1 nets (carrier)

USB end → far end. **J8A** = DevKit **J1**, **J8B** = DevKit **J3**.

| Socket | DevKit header | Pins netted on carrier |
|---|---|---|
| J8A | J1 | 3V3 (pin 1), GPIO 4–7, 17, 18, 8–12, 5V, GND |
| J8B | J3 | all NC on carrier (mechanical only) |

Reader UART on the carrier: GPIO17 = ESP RX, GPIO18 = ESP TX (factory map).

### NPN drivers (TO-92)

Pads left → right with flat face toward the silk “CBE” mark: **C – B – E**.

| Ref | C | B | E | Base resistor |
|---|---|---|---|---|
| Q2 (relay) | `RELAY_IN` | `Q2_BASE` | `GND` | R2 1k ← GPIO10 |
| Q1 (buzzer) | `BUZZ_SW` | `Q1_BASE` | `GND` | R1 1k ← GPIO7 |

Confirm against your transistor datasheet (2N2222 vs BC547 pinouts differ).

## Open in KiCad

1. Install [KiCad 8+](https://www.kicad.org/).
2. Open `carrier-v0.kicad_pro`.
3. Open the PCB: **Board Editor**.
4. Run **Fill all zones** (B.Cu GND pour) and **DRC**.
5. Tweak track positions if your module body keepouts need space.

The PCB was generated by script so expect to nudge silkscreen and re-pour GND
once before fab.

## Export Gerbers for JLCPCB

1. PCB Editor → **File → Fabrication Outputs → Gerbers** (`gerbers/`).
2. Enable layers: `F.Cu`, `B.Cu`, `F.SilkS`, `B.SilkS`, `F.Mask`, `B.Mask`, `Edge.Cuts`.
3. **Generate drill files** (Excellon).
4. Zip the `gerbers/` folder → upload to JLCPCB.
5. Options that usually work: 2 layers, 1.6 mm, HASL, 1 oz copper.

Suggested first order: **5 pcs**.

### PCBA (passives + sockets + connectors + NPNs)

BOM + centroid: [`fab/`](fab/) (`bom-jlcpcb.csv`, `cpl-jlcpcb.csv`, steps in `fab/README.md`).

- Enable **Standard** PCB Assembly (THT + SMT), top side.
- Assemble C1/C2, headers, screw terminals, DevKit socket, Q1/Q2, R1/R2/R3.
- **Do not** assemble DevKit / relay module / buzzer / LED / RTC — those plug in.

## Assembly notes

1. If bare PCB: solder SMDs (C2, R3), then THT (C1, transistors, headers, terminals).
   If PCBA, skip to continuity / module plug-in.
2. Continuity: `P5V` not shorted to `GND`.
3. Power via panel DC jack → J1 DCIN only: ~5 V on star, ~3.3 V on J8A pin 1.
4. `/setup`: relay **active-high off**; buzzer **active-high on**.
5. See checklist in `docs/carrier-v0.md`.

## Out of scope

On-board ESP32-S3 RF, PoE, enclosure STEP. AliExpress “DevKitC” clones with a
different pin order are **not** supported on this socket — use Espressif
DevKitC-1 (or a verified pin-compatible board).
